# Monte-Carlo-simulation
This Monte Carlo simulation simulates 10,000 outcomes of stock prices over a 252 trading day period, using real-market data from the S&P500. Probable future price paths for stocks within the S&P500 have been modelled to estimate future returns of these stocks, volatility, and risk. Key features of this model are; 10,000 projections, real-market data, NumPy implementation, distribution plots and statistics, and a reproducible model for a number of different stocks. The Monte Carlo simulation works by estimating the return on investment for shares within the S&P500, using actual market data to do so, generating 10,000 paths using Brownian motion to simulate randomness within these paths. Once the paths have been modelled, they are plotted graphically using the matplotlib library. To further improve this simulation, comparisons to the Black Scholes model should be made to interpret accuracy of this model. Another addition, is adding a VaR and conditional VaR to produce an estimate of the maximum and average losses for the investment portfolio respectively.
